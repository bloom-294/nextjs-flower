## ブランチ命名規則
先頭にプレフィックスをつけましょう！<br/>
変更内容が一目でわかるようになります。

```text
# 例：Issue #42（ラベル: ui, feature）でボタンを作成するとき
feature/primary-button

# 例：Issue #55（ラベル: bug, layout）でヘッダー崩れを直すとき
fix/top-layout

# 例：Issue #60（ラベル: Storybook, doc）でガイドを追加するとき
docs/add-guide
```

## コミットメッセージの例

Issue番号を末尾につけると、GitHub上で自動リンクされます！

```text
feature: ログインフォームのUIを実装 (#42)
fix: スマホ表示時のメニュー開閉バグを修正 (#55)
docs: StorybookにGit運用ルールページを追加 (#60)
test: Buttonコンポーネントのテストを追加 (#65)
```


## プルリクエスト（PR）作成時のチェックリスト
　PRは自動で生成される雛形に沿って作成しましょう！<br/>
　以下は追加の共通の確認事項です。

* [ ] Storybook上で表示崩れやエラーがないか確認した
* [ ] レスポンシブ（PC / SP）の表示を確認した
* [ ] 不要な `console.log` やコメントアウトを削除した
